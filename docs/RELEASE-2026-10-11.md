## GitHubへの反映

1. ZIPを展開します。
2. 展開した中身を既存リポジトリのルートへ上書きします。`package.json` と `.github/workflows/deploy.yml` がリポジトリ直下の対応位置にあることを確認します。隠しフォルダ `.github` も含めてください。
3. GitHub Pagesの公開元を **GitHub Actions** に設定します。
4. 必要ならリポジトリのActions secretに `VITE_VISIT_PASSWORD` を設定します。
5. `main` にコミット・pushし、Actionsの結果を確認します。既存PWAでは更新通知から更新を適用します。

ZIPには `node_modules`、`dist`、テスト画像、個別環境設定や一時ファイルを含めません。ZIP自体をGitHubに置くだけではサイトは更新されません。この作業ではGitHubへのpush・公開は行っていません。
